## MATLABでの確認

このフォルダーの prepare_step01.m を実行してください。
関数の解決先と監視出力の一致を確認し、モデル更新後に新モデルを開きます。
その後シミュレーションを実行し、従来の結果と比較してください。
今回の原本では監視のみ別関数でしたが、監視値は接地判定にも使用されるため、
接地以降の応答に差が出た場合は判定時刻と N_ground を比較してください。
